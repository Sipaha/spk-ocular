## SPK Ocular 0.1.0

- Explore Kubernetes and Docker Compose in a native Linux, Windows or macOS desktop application.
- Work with live resource tables, multiple namespaces, global favorites, logs,
  terminals, local port forwarding, and reviewed resource changes.
- Search current and recently opened objects within selected namespaces.
  Opening a result selects its resource section and table row.
- Install DEB/RPM, Windows MSI or macOS DMG packages, or use portable archives
  for x86-64 and AArch64.
  Every downloadable artifact has a SHA-256 checksum.
- Agent log access covers time intervals, grep, bounded live reading and file
  export under the same scoped permission. API output has explicit budgets.

## Русский

- SPK Ocular — локальное desktop-приложение для Kubernetes и Docker Compose.
- Живые таблицы, несколько namespace, общее избранное, логи, терминалы,
  локальные туннели и изменение ресурсов с предварительным просмотром.
- Поиск текущих и недавних объектов ограничен выбранными namespace.
  Открытие результата выбирает его раздел и строку таблицы.
- Пакеты DEB/RPM для Linux, MSI для Windows, DMG для macOS и архивы
  для x86-64 и AArch64.
  Для каждого файла опубликована контрольная сумма SHA-256.
- Одно разрешение на логи даёт агентам диапазоны времени, grep, ограниченное
  потоковое чтение и выгрузку в файл. Размер ответов API ограничен.
