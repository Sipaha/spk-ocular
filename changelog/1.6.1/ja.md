# SPK Ocular 1.6.1

- Linux の DEB/RPM パッケージで必要な glibc を 2.39 から 2.35 以降に引き下げました。GTK 3 と WebKit2GTK 4.1 があれば、Ubuntu 22.04 と Debian 12 に通常の方法でインストールできます。
- Linux の両アーキテクチャで、公開前に Ubuntu 22.04 上のネイティブなインストール、ブラウザーモード、GTK ウィンドウを検証します。パッケージ検証では、宣言した最低 glibc バージョンを超えるシンボルを必要とする実行ファイルも拒否します。
- ネイティブ検証アーカイブに、従来の六つのプラットフォームの証拠に加えて Ubuntu 22.04 の二つのレポートとスクリーンショットを収録します。これはテスト環境のカーネル上での X11 とユーザー空間の検証であり、すべてのカーネル、GPU ドライバー、Wayland セッションの認証ではありません。
