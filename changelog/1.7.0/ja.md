# SPK Ocular 1.7.0

- Kubernetes のリソース一覧は、要求した種類と選択した namespaces の全件を、共有のコンパクトなキャッシュ、小さな自動ページ、watch で読み込みます。セッション共通の読み取り制限と未使用キャッシュの保持制限により、不要な API アクセスとメモリ保持を抑えます。
- All Namespaces の読み込みが大きすぎる場合は停止し、特定の namespaces の選択を求めます。一部だけの一覧を全件として表示しません。
- 統一された更新アイコンで一覧を再取得でき、完了まで回転します。読み込み中は経過時間と、取得可能な場合は受信したインベントリデータ量を表示します。キャンセルすると専用の表示に切り替わり、再試行または新しい接続まで維持されます。
- クラスターグラフは接続ごとに明示的にクリックした後で読み込みます。選択、検索、詳細の表示でカメラ位置を維持します。
- 接続の選択、リソースの種類の表示、表のツールチップ、選択範囲内でのコマンドパレットの移動、ログの選択を改善しました。選択したリソースのポートを再描画しても、同じ情報を重複して要求しません。
- ローカルのインベントリとメモリの測定値、生データ、方法、制約は `docs/performance.md` に記載しています。あらゆる本番環境の性能を保証するものではありません。
