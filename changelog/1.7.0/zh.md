# SPK Ocular 1.7.0

- Kubernetes 资源列表通过共享的紧凑缓存、自动小分页和 watch，完整加载所需资源类型及所选 namespaces。会话共用的读取预算和闲置缓存保留限制可减少不必要的 API 请求与内存保留。
- All Namespaces 查询过大时会停止，并要求选择具体的 namespaces，不会将部分列表显示为完整结果。
- 统一的刷新图标会重新读取列表，并旋转至操作结束。加载时显示已用时间，以及可获取时的已接收清单数据量。取消后显示持久的已取消提示；只有重试或建立新连接才会重新加载。
- 集群关系图仅在每次连接后明确点击时加载。选择、搜索和打开详情不会改变视角。
- 改进了连接选择、资源类型标签、表格提示、命令面板在所选范围内的导航及日志选择。重新渲染所选资源的端口时，不再重复请求相同信息。
- 本地清单与内存测量、原始数据、方法和限制见 `docs/performance.md`；这些结果并非对所有生产集群的性能保证。
- 资源列表避免重复解码 JSON，减少加载大型 Kubernetes 资源清单时的 CPU 开销。
