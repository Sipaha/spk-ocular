# SPK Ocular 1.7.0

- Списки ресурсов Kubernetes целиком загружают выбранный тип и namespaces через общий компактный кэш, небольшие автоматические страницы и watch. Общий бюджет чтения сессии и ограниченное хранение неиспользуемых кэшей сокращают лишние обращения к API и удержание памяти.
- Слишком большая загрузка All Namespaces останавливается с предложением выбрать конкретные namespaces, без выдачи неполного списка за полный.
- Одинаковые иконки обновления перечитывают списки и вращаются до завершения. Во время загрузки показываются прошедшее время и полученный объём данных inventory, если он доступен. Отмена заменяет список сохраняющейся заглушкой; «Повторить» или новое подключение запускают загрузку снова.
- Граф кластера загружается только после явного нажатия для каждого подключения. Выбор, поиск и открытие подробностей сохраняют положение камеры.
- Доработаны выбор подключений, подписи типов ресурсов, подсказки таблиц, поиск в выбранной области через командную палитру и выделение логов. Перерисовка портов выбранного ресурса больше не повторяет тот же запрос информации.
- Локальные замеры списков и памяти, исходные данные, методика и ограничения описаны в `docs/performance.md`; это не универсальные гарантии производительности production-кластеров.
