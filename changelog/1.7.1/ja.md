# SPK Ocular 1.7.1

- 大きなログパネルを開いたままウィンドウを縮小すると、ページ全体がスクロールし、ステータスバーの下に空白ができる問題を修正しました。ログパネルは利用可能な高さに収まり、アプリの上部と下部のバーはその位置を保ちます。
- Make によるローカルビルドでは、秒単位の UTC ビルド時刻と短い Git リビジョンが、下部バー、バージョン情報ダイアログ、version コマンドに表示されるようになりました。公開リリースのバージョン番号は変更されません。
- Helm upgrade のキャンセル競合を修正しました。操作の後処理によって、成功済みのアップグレードが失敗扱いになる可能性がありました。実行中のキャンセルとタイムアウトは引き続き有効です。
