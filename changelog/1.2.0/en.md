# SPK Ocular 1.2.0

## Investigation workspace

- Explore a Kubernetes cluster graph with namespace regions, UID-based resource relationships and an optional declared Service/Ingress/Gateway route layer. This shows configuration, not measured network traffic.
- Inspect workload Events on a time axis with ownership groups, warning and time filters, and direct resource navigation. Refresh reads an explicit bounded snapshot; Kubernetes retention and partial coverage remain visible.
- Explain ServiceAccount RBAC through binding and role provenance, and check a request as the current connection with the server. Declared grants and authoritative self-access decisions remain separate.
- Compare two explicitly selected saved resources, including resources on different connected targets. Normalized read-only YAML hides volatile service fields by default; Secret payloads and unsaved drafts are excluded.
- Pin read-only properties and retain selected log references, ended terminal slots and panel layout across restarts. Restore never connects or replays commands: connect and resume explicitly. Stored workspace metadata contains no YAML, values, logs or drafts.

## Everyday interface

- Download all retained source log history independently of the viewer’s line limit and filters, with streamed file writes, progress/cancellation and explicit failure instead of an incomplete file. Provider retention and export limits remain visible.

- Deployment revisions use a compact table with retained images, ready replicas, dates, change causes and read-only YAML/comparison actions.
- Inspector and log actions use consistent compact icons with descriptive hover/focus tooltips, keyboard access and visible toggle states. All eight UI languages remain complete.
- Incoming product and author links let the destination choose its language; explicit internal language and SEO routes remain available.
- License collection works when frontend embed staging is empty or missing and reports the underlying Go error when dependency inspection fails.

Desktop packages cover Linux, Windows and macOS on amd64 and arm64. Installer signing and runtime requirements remain documented in the installation guide.
