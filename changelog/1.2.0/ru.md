# SPK Ocular 1.2.0

## Рабочее пространство для диагностики

- Граф Kubernetes с областями пространств имён, связями ресурсов по UID и дополнительным слоем объявленных маршрутов Service/Ingress/Gateway. Это конфигурация, а не измеренный сетевой трафик.
- События рабочих нагрузок на временной оси: группы владельцев, фильтры предупреждений и времени, переход к ресурсам. Обновление читает ограниченный снимок Events; срок хранения Kubernetes и неполное покрытие видны явно.
- Разбор RBAC ServiceAccount с источниками прав в привязках и ролях, а также серверная проверка запроса от имени текущего подключения. Объявленные права и фактическое решение сервера показаны отдельно.
- Сравнение двух явно выбранных сохранённых ресурсов, в том числе из разных подключённых окружений. Нормализованный YAML доступен только для чтения; изменчивые служебные поля скрыты по умолчанию, данные Secret и несохранённые правки исключены.
- Закрепление свойств только для чтения, сохранение выбранных ссылок на логи, завершённых слотов терминала и размеров панелей между запусками. Подключение и возобновление всегда явные; команды не воспроизводятся. YAML, значения, логи и черновики в сохранённое состояние не попадают.

## Повседневный интерфейс

- Скачивание всей сохранённой истории источника логов независимо от лимита строк и фильтров панели: потоковая запись, прогресс, отмена и явная ошибка вместо неполного файла. Срок хранения источника и ограничения экспорта показаны явно.

- Ревизии Deployment представлены компактной таблицей: образы, готовые реплики, даты, причины изменений, просмотр YAML и сравнение только для чтения.
- Действия в инспекторе и логах представлены компактными иконками с описательными подсказками при наведении и клавиатурном фокусе. Состояния переключателей видны, все восемь языков интерфейса сохранены.
- Входящие ссылки на продукт и автора не навязывают язык; внутренний выбор языка и SEO-маршруты остаются явными.
- Сбор лицензий работает при пустом или отсутствующем каталоге для встраивания интерфейса и показывает исходную ошибку Go при сбое анализа зависимостей.

Пакеты приложения доступны для Linux, Windows и macOS на amd64 и arm64. Требования к системам и состояние подписей установщиков описаны в руководстве по установке.
