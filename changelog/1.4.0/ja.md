# SPK Ocular 1.4.0

## 検索とクイックツール

- Ctrl+K は元の検索結果がない場合に限り、ロシア語または互換性のあるウクライナ語配列で入力した英語 QWERTY 検索を復元します。入力、スコープ、リソースの識別情報は保持され、翻訳されたヒントに復元後の検索が表示されます。
- 検索からオブジェクトを開くと、選択した表の行にフォーカスが移ります。個別の Pod のログ、ターミナル、ファイルは、実行中の既定コンテナを使用し、利用できなければ最初の実行中コンテナを使用します。完了した Pod のログも引き続き利用できます。複数のレプリカでは Pod の明示的な選択を維持し、右クリックで詳細設定を開きます。
- ログを開く、または再び開くと、ログ領域にフォーカスが移ります。Follow のツールチップとキーボードヘルプに End を表示します。テキスト入力欄では通常の End 操作を維持します。

## インターフェース、信頼性、パフォーマンス

- モーダルは背後のスクロールバーとパネルの区切り線を覆います。表のフォーカス表示はヘッダーと行を含み、メニューは下部パネルより上に、ツールチップはボタンの近くに表示されます。
- 読み取り専用と設定ダイアログで、フォーカス、Tab、閉じる操作を統一しました。未保存の編集に対する保護は維持されます。
- エージェントの履歴はフィルター変更後の古い応答を拒否し、過去の対象を保持し、選択した言語で日付を表示します。リソースの関連、Deployment のリビジョン、Helm リソースはコンパクトで整列した表を使用します。
- UI の HTTP リクエストには本文サイズと読み取り時間の上限があります。セッションの識別確認と待機中のインベントリ要求のキャンセルにより、古い読み取りが置き換え後のセッションに移ることを防ぎます。権限、スコープ、プロバイダーの上限は変更しません。
- ログの正規表現検索は差分のバッチを処理し、worker に履歴を二重保存しません。Compose の投影ではローカル索引を使い、行が未変更の場合や状態だけの更新では不要な処理を減らします。
- 8 言語、デスクトップとブラウザーの共通実行ファイル、6 種類のプラットフォーム構成に対する必須検証を維持します。
