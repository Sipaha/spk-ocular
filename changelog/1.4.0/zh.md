# SPK Ocular 1.4.0

## 搜索和快捷工具

- 仅当原始查询没有结果时，Ctrl+K 才会恢复使用俄语或兼容乌克兰语键盘布局输入的英语 QWERTY 查询。输入文本、范围和资源身份保持不变，本地化提示会显示恢复后的查询。
- 从搜索打开对象后，焦点移至表格中选中的行。具体 Pod 的日志、终端和文件优先使用正在运行的默认容器，否则使用第一个正在运行的容器。已结束 Pod 的日志仍然可用。多个副本之间仍需明确选择 Pod；右键保留完整设置。
- 打开或重新打开日志会将焦点移至日志区域。Follow 的提示和键盘帮助显示 End；文本输入框保留 End 的常规行为。

## 界面、可靠性和性能

- 模态窗口覆盖背景滚动条和面板分隔线。表格焦点框包含表头和行；菜单位于底部面板上方，提示紧邻按钮显示。
- 只读和设置对话框统一了焦点、Tab 和关闭行为。未保存编辑的保护保持不变。
- 代理历史在筛选条件变更后拒绝过期响应，保留历史目标，并按所选语言显示日期。资源关系、Deployment 修订和 Helm 资源使用紧凑且对齐的表格。
- UI HTTP 请求具有正文大小和读取时间限制。会话身份检查以及等待中清单请求的取消，防止过期读取转到替换后的会话。权限、范围和提供程序预算保持不变。
- 日志正则表达式搜索处理增量批次，不再在 worker 中保留第二份历史。Compose 投影使用局部索引；未更改的行和仅状态更新避免重复处理。
- 保留全部八种界面语言、桌面和浏览器共用的可执行文件，以及六种平台组合的强制发布验证。
