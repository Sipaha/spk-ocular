# SPK Ocular 1.1.1

- Сборка использует Go 1.26.9 и golang.org/x/net v0.60.0 с исправлениями недавно опубликованных уязвимостей HTTP/2.
- Просмотр файлов контейнеров Kubernetes и Docker: дерево с кешированием папок, переходы по символьным ссылкам, подсветка синтаксиса и защищённое редактирование UTF-8 файлов до 2 МиБ. В desktop-приложении можно скопировать целый файл или папку через системный выбор каталога; данные передаются потоком, существующие имена не перезаписываются.
- Логи открываются в отдельном нативном окне с сохранением единственного потока. Для текстового экспорта можно выбрать место сохранения. Видны все уровни логов; фильтрация по тексту и поиск сохранены.
- Для workload с несколькими Pod’ами можно выбрать Pod, для Pod с несколькими контейнерами — контейнер. ПКМ на Logs, Terminal или Files открывает полную настройку; поле команды есть только у Terminal. При одном варианте ЛКМ открывает инструмент сразу, а в настройке селектор остаётся видимым.
- Добавлены сохранённые ревизии Deployment: просмотр и сравнение Pod-template YAML с текущим Deployment или другой ревизией, без редактирования в этом разделе.
- Горячие клавиши используют физические клавиши независимо от раскладки, в том числе в редакторе. Исправлены повторы кириллицы в терминале, промежуточные обновления размера при перетаскивании и оставшийся фокус на границе панели.
- Улучшены пространство файлового инспектора, изменение ширины дерева, кешированные счётчики, строки загрузки и пустых папок, показ ошибок без сдвига интерфейса. Связанные ресурсы оформлены компактными строками; действия с окном логов представлены иконками справа.

Для файловых операций нужен работающий Linux-контейнер с необходимыми утилитами: sh для просмотра, readlink для символьных ссылок и tar для скачивания. На нативное копирование ограничение редактора в 2 МиБ не распространяется. Для скачивания файлов контейнера из браузерного режима требуется desktop-приложение. Небезопасные записи архива и совпадения имён назначения отклоняются.

Нативные пакеты доступны для Linux, Windows и macOS на amd64 и arm64. Статус подписи установщиков и notarization не изменён; файлы предыдущих релизов не переписываются.
