# SPK Ocular 1.1.1

- Go 1.26.9 と golang.org/x/net v0.60.0 を使用し、新たに報告された HTTP/2 の脆弱性を修正しました。
- Kubernetes と Docker のコンテナファイルを閲覧できます。フォルダツリーのキャッシュ、シンボリックリンクの移動先、構文強調表示、2 MiB までの UTF-8 ファイルの保護付き編集に対応しました。デスクトップアプリでは、ネイティブのディレクトリ選択からファイルやフォルダ全体をコピーできます。既存の名前は上書きしません。
- ログを独立したネイティブウィンドウで表示し、ストリームは一つのまま維持します。テキスト書き出しの保存先を選択できます。すべてのログレベルを表示し、テキストフィルタと検索も引き続き利用できます。
- 複数のポッドを持つワークロードではポッドを、複数のコンテナを持つポッドではコンテナを選択できます。Logs、Terminal、Files を右クリックすると詳細設定が開きます。コマンド欄は Terminal のみです。選択肢が一つなら左クリックで直接開き、設定画面ではセレクタを表示します。
- 保存されている Deployment のリビジョンを閲覧し、読み取り専用のポッドテンプレート YAML を現在の Deployment や別のリビジョンと比較できます。
- エディタを含むショートカットがキーボード配列によらず物理キーに従います。キリル文字の重複入力、ドラッグ中の端末サイズ更新、区切り線に残るフォーカスを修正しました。
- ファイルインスペクタの表示領域、ツリー幅の調整、キャッシュされた件数、読み込み・空フォルダ行を改善しました。エラーでレイアウトが移動しません。関連リソースはコンパクトな行で表示し、ウィンドウ操作は右端のアイコンになりました。

ファイル操作には、実行中の Linux コンテナと sh が必要です。リンクには readlink、ダウンロードには tar が必要です。ネイティブダウンロードにはエディタの 2 MiB 制限はなく、デスクトップアプリが必要です。危険なアーカイブ項目や保存先の名前の競合は拒否します。

Linux、Windows、macOS の amd64 と arm64 向けネイティブパッケージを提供します。署名・公証の状態は変更せず、過去のリリースファイルも書き換えません。
