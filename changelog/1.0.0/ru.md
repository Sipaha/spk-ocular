## SPK Ocular 1.0.0

Локальное приложение для работы с Kubernetes и Docker. Нативные пакеты для
Linux, Windows и macOS доступны на x86-64 и ARM64.

### Изменения по сравнению с 0.1.0

- Интерфейс доступен на русском, английском, упрощённом китайском, испанском,
  немецком, французском, бразильском португальском и японском. Меню с родными
  названиями языков сохраняет выбор между запусками. Переключение языка сохраняет
  рабочие области и правки. Идентификаторы ресурсов, исходные данные, логи и
  манифесты остаются на исходном языке. Документация и существующие скриншоты
  остаются на английском.
- Явно открытые подключения сохраняются при чтении чартов Helm, редактировании
  values, сворачивании окна и переключении целей. При изменении конфигурации
  приложение автоматически проверяет новое подключение. Проверки подтверждённого
  плана и версии по-прежнему защищают запись; восстановление связи не повторяет
  изменяющие операции.
- Helm использует общую таблицу и панель деталей: сортировку, сохранение ширины
  колонок и перетяжку разделителя. Список целей в окне разрешений агентов также
  меняет ширину. Пустое состояние находится внутри таблицы. При смене объекта
  панель сохраняет вёрстку под индикатором загрузки, а старые действия блокируются.
- Можно просматривать и управлять явно подключёнными файлами kubeconfig и
  зашифрованными пользовательскими конфигурациями. Изменения проходят review,
  несохранённые правки ресурсов защищены. Пароли и открытые учётные данные не
  сохраняются в настройках интерфейса.
- Нажатие на название и логотип Ocular открывает окно «О программе»: версия
  текущей сборки, лицензия Apache 2.0, ссылки проекта и профиль автора — Павла
  Симонова. Иконка одинакова на сайте, в браузере и нативном приложении.
- В дистрибутивы включены сведения о лицензиях используемых сторонних компонентов
  вместе с лицензией приложения Apache 2.0.

### Загрузка и установка

Выберите установщик для своей ОС и архитектуры: DEB/RPM для Linux, MSI для
Windows или DMG для macOS. Есть переносимые архивы нативного приложения и локальной
браузерной версии. У каждого пакета есть файл `.sha256`; `SHA256SUMS` содержит
контрольные суммы всего набора.

Linux требует Ubuntu 24.04+ или совместимую систему с glibc 2.39+, GTK 3 и
WebKit2GTK 4.1. Windows требует Windows 10/11 и WebView2, macOS — версию 12 или
новее. Пакеты Windows не подписаны; приложения macOS имеют ad-hoc подпись, но
не нотарифицированы. Ocular использует существующие окружения Kubernetes и
Docker и не предоставляет контейнерный движок или виртуальную машину.
Автоматическое обновление внутри приложения пока запланировано.
