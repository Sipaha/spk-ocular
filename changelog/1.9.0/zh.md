# SPK Ocular 1.9.0

- 资源列表、Helm、Graph、Timeline、Security 和 RBAC 统一了工具栏、保留内容的加载、进度、取消及重试操作。Helm 位于左侧 Storage 之后。
- Pod 属性分别展示普通、init 和 debug 容器，保留 Sidecar 标记，并正确换行显示长名称及镜像。
- 所有界面语言均使用本地时间、24 小时制和 dd.mm.yyyy 日期格式；悬停可查看原始 ISO 时间戳。
- 可直接从 Deployment 属性进行扩缩容。操作确认显示连接名称；减号和加号可在允许范围内调整副本数，随后仍需审查。
- 选择比较基线不再移动工作区。文本差异包含上下文，并采用有界分页。
- 新的 container-exec 权限直接覆盖所选命名空间或项目，无需选择资源类型。现有受限授权和确认设置保持不变；复选框的启用和禁用状态更清楚。
- 日志显示连接和资源，使用“全部时间”，并将过滤放在本地搜索之前。后端逐步扫描受限的近期历史，加载期间显示匹配结果，同时捕获新增日志。限制和不完整结果会明确提示。
- 开始下载会自动打开 Downloads，默认保存到系统下载文件夹，不再询问位置。右键单击日志下载可选择位置。同名文件自动添加序号；可在面板取消进行中的下载，包括独立日志窗口的任务。
- 单击已完成的下载行即可打开文件。成功打开文件或显示所在文件夹后关闭面板。进度变化不再改变面板位置、行高或日志底栏布局。
- 连接进度不再移动图标和标题。YAML 不再先闪现纯文本；准备打开时会预加载编辑器，切换资源时复用同一实例，并保留草稿保护。
