# SPK Ocular 1.9.0

- Списки ресурсов, Helm, Graph, Timeline, Security и RBAC используют единые панели инструментов и загрузку с сохранением содержимого, прогрессом, отменой и повторной попыткой. Разделы Helm находятся слева после Storage.
- В свойствах Pod отдельно показаны обычные, init- и debug-контейнеры; сохранены отметки Sidecar, длинные имена и образы переносятся внутри панели.
- Календарные даты во всех языках интерфейса используют местное время, 24-часовой формат и dd.mm.yyyy; исходный ISO timestamp доступен при наведении.
- Масштабирование Deployment доступно прямо из свойств. В подтверждении показывается имя подключения, кнопки «−» и «+» меняют число реплик в допустимом диапазоне перед Review.
- Выбор базы сравнения больше не сдвигает рабочую область. Текстовые различия показывают окружающий контекст с ограниченной постраничной загрузкой.
- Новые разрешения container-exec действуют на выбранный namespace/project без выбора типов ресурсов. Существующие ограниченные разрешения и настройки подтверждения сохранены; состояния галочек стали отчётливее.
- Логи показывают подключение и ресурс, используют «За всё время» и ставят фильтр перед локальным поиском. Серверная фильтрация постепенно читает ограниченную недавнюю историю; найденные строки видны во время загрузки, новые строки принимаются параллельно. Лимиты и неполные результаты отмечаются явно.
- Downloads открывается автоматически; файлы сохраняются в системную папку загрузок без вопросов. ПКМ по скачиванию логов позволяет выбрать место. При совпадении имён добавляется номер; отмена доступна в Downloads, в том числе для отдельных окон логов.
- Завершённый файл открывается по клику на строку. После успешного открытия файла или папки панель закрывается. Положение панели, высота строк и нижняя строка логов не скачут при изменении прогресса.
- Прогресс подключения не сдвигает иконку и имя. YAML открывается без вспышки обычного текста, подгружается по намерению открыть редактор и сохраняет его экземпляр при смене ресурса; защита черновиков остаётся прежней.
