# SPK Ocular 1.6.0

## エージェントのコンテナ内コマンド

- ローカルエージェントは `GetExecInfo`、`PrepareExec`、`RunExec` でインスタンスを取得し、有限コマンドを準備・実行できます。stdout/stderr を別々の base64 として返し、観測した終了状態、出力上限、時間制限を示します。
- 独立した `exec` 権限には種別の明示とインスタンス/コンテナの選択が必要です。既定では各コマンドを確認し、正確な argv、有限 stdin、対象、制限を表示します。常駐対話シェル、暗黙のシェル、attach、自動再実行は提供しません。
- Kubernetes namespace と Docker Compose project の範囲、対象の識別、UID、設定リビジョンを検証します。権限変更は通信を取り消しますが、リモートプロセスの終了は best effort です。不完全・不明な結果を明示します。単独 Docker コンテナはプロジェクト権限を継承しません。
- Exec はコンテナ権限を使い、マウントされた秘密情報の読み取りやコンテナ/ホストデータの変更が可能です。コマンド、入力、出力を監査ログに保存しません。既存の権限に exec を自動追加しません。

## 修正

- ダウンロード削除の確認は準備完了後に確実にキャンセルへフォーカスします。
- Docker の有限入力は stdout/stderr を維持して EOF を送信します。入力なしのコマンドは stdin を切り離します。未対応の入力通信は開始前に拒否します。
- ドイツ語のエージェント確認文の文字コードを修正しました。新しい exec 設定と確認は全八言語に翻訳済みです。

配布物は共通のデスクトップ/ブラウザー実行ファイルを維持し、全六種のネイティブ OS/アーキテクチャ構成で検証します。
