## SPK Ocular 0.1.0

Локальное настольное приложение для Kubernetes и Docker на Linux, Windows
и macOS, для x86-64 и ARM64. Все функции бесплатны для людей и компаний
любого размера, оборота и объёма финансирования.

- Диагностика ресурсов, событий и связей. Поиск в выбранных пространствах имён,
  избранное и подробности ресурсов рядом с логами.
- Отдельные контейнеры Docker и группировка проектов и сервисов Compose.
  Логи, терминалы и действия с контейнерами с предварительной проверкой.
- Встроенный Helm: репозитории чартов и OCI-реестры, установка, обновление,
  история ревизий, откат и удаление. Версии чартов, values и изменения можно
  проверить до применения. Отдельный Helm CLI не нужен.
- Доступ локальных агентов через именованные группы разрешений. Доступ можно
  приостановить без потери настроек; защищённые изменения требуют подтверждения.
  Разрешения общие для агентов вашего пользователя ОС. Отдельные контейнеры
  Docker и Helm пока доступны только в интерфейсе и не входят в разрешения агентов.
- Сохранение выбранных пространств имён, фильтров, избранного и ширины колонок.
  Несколько источников логов, терминалы и проброс портов в одном рабочем окне.

### Скачать и установить

Выберите установщик для своей системы и архитектуры: DEB/RPM для Linux,
MSI для Windows или DMG для macOS. Также доступны переносимые архивы
настольного приложения и локального браузерного интерфейса. Для каждого пакета
есть файл `.sha256`; общий список контрольных сумм находится в `SHA256SUMS`.

Linux: Ubuntu 24.04+ или совместимая система с glibc 2.39+, GTK 3 и WebKit2GTK 4.1.
Windows: Windows 10/11 и WebView2. macOS: версия 12 или новее.
Пакеты Windows не подписаны; macOS использует ad-hoc-подпись без нотариализации.
Перед разрешением установки проверьте источник и контрольную сумму.

Ocular работает с существующими окружениями Kubernetes и Docker, не предоставляет
контейнерный движок или виртуальную машину. Разработка поддерживается только
необязательными криптопожертвованиями; донаты не открывают дополнительные функции.
