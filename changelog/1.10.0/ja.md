# SPK Ocular 1.10.0

- プロセス内 MCP サーバーからローカルエージェントを接続し、明示的な権限と操作レビューを維持します。Codex と Claude Code は要求時に設定でき、他のクライアントには手動設定を用意しました。 従来のローカルプロトコルは MCP Streamable HTTP に置き換わるため、既存クライアントは再設定が必要です。
- Argo CD と Flux のネイティブ画面でアプリケーション、コントローラーの状態とリソースリンクを確認できます。編集・スケールのレビューには利用可能な GitOps 所有情報を表示します。
- 明示的に開始する範囲限定の診断読み取りで、workloads、Service/Ingress のネットワーク経路、Helm リリースを調査し、情報源と証拠の不足を示します。
- ラベル列と保存済みテーブルビューを追加しました。Secret の内容を読まずに cert-manager Certificate の状態と更新情報を確認できます。
- 明示的に選んだ Prometheus メトリクス履歴と既存の VPA 推奨を読み取り、状況に応じた workload の設定・信頼性チェックを行えます。
- 既存の名前空間別 Trivy 設定/RBAC レポートとポリシーレポートを確認できます。クラスター全体のレポートと選択した Gatekeeper 制約の監査は別々の同意が必要で、証拠がない場合は不明のままです。
- KRR レポートをバックエンドの一時ストレージへ取り込むか、一時 Kubernetes Job をレビューしてから KRR を実行できます。選択した Node の名前空間別リソース宣言を表示し、実測の空き容量とは区別します。
- サイズを制限したオフライン Polaris JSON 監査レポートをローカルで取り込めます。取り込み時にスキャナーをインストールしたりクラスターへ問い合わせたりしません。
- 明示的に選択した workloads のログを合成し、重複の処理、出所表示、フィルター、有限範囲のエクスポートに対応しました。
- レビュー付き Node Shell・Files ヘルパーはライフサイクルを共有し、クリーンアップ結果を保持します。Files は削除と表示したファイルの選択に対応し、Alt+Shift+Enter で Files/Shell を別ウィンドウへ移動・再ドックできます。
- オフラインヘルプと隔離された課題型入門コースで Kubernetes を学べます。診断フィードバックを改善し、8 言語に対応しています。
- Pod 選択で rollout のリビジョンと準備状態を説明し、比較の案内を改善しました。古い upstream の終了時も転送接続の再接続状態を保持します。
- リリースビルドは証明書の信頼性に関するセキュリティ修正を含む Go 1.26.10 を使用します。
