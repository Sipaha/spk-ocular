# SPK Ocular 1.10.0

- Подключайте локальных агентов через встроенный MCP-сервер с явными разрешениями и подтверждением операций. Настройка Codex и Claude Code выполняется по запросу; для других клиентов доступна ручная конфигурация. Доступ агентов переведён со старого локального протокола на MCP Streamable HTTP; существующие клиенты нужно перенастроить.
- Просматривайте Argo CD и Flux: состояние приложений и контроллеров, связи с ресурсами. Проверка перед редактированием и масштабированием показывает доступные сведения о владельце GitOps.
- Исследуйте workloads, сетевые пути Service/Ingress и релизы Helm через ограниченные диагностические запросы с явным запуском, указанием источников и пробелов в данных.
- Добавляйте колонки меток и сохраняйте представления таблиц. Проверяйте состояние Certificate cert-manager и сведения о продлении без чтения содержимого Secret.
- Читайте явно выбранную историю метрик Prometheus и существующие рекомендации VPA; проверяйте конфигурацию и устойчивость workloads с учётом контекста.
- Просматривайте существующие namespaced-отчёты Trivy о конфигурации/RBAC и отчёты политик. Для общекластерных отчётов Trivy/политик и аудита выбранного ограничения Gatekeeper требуется отдельное согласие; отсутствие данных не означает успех.
- Импортируйте отчёты KRR во временное хранилище бэкенда или проверяйте временный Kubernetes Job перед запуском KRR. Смотрите декларации ресурсов по namespace выбранного Node, не принимая их за измеренную свободную ёмкость.
- Импортируйте ограниченные JSON-отчёты Polaris локально: импорт не устанавливает сканер и не обращается к кластеру.
- Объединяйте логи явно выбранных workloads с устранением пересечений, указанием источников, фильтрацией и конечным экспортом.
- Открывайте Node Shell и Files через предварительную проверку, с общим жизненным циклом helpers и сохранением результатов очистки. Files поддерживает удаление и выделение показанного файла; Alt+Shift+Enter отделяет Files/Shell в окно и возвращает обратно.
- Изучайте Kubernetes с офлайн-справкой и изолированным вводным курсом практических заданий, понятной диагностикой и восемью языками интерфейса.
- Выбор Pod поясняет ревизию rollout и готовность; подсказки сравнения стали понятнее. Пробросы портов сохраняют состояние переподключения при завершении старого upstream.
- Релиз собран на Go 1.26.10 с исправлением безопасности проверки доверия сертификатам.
