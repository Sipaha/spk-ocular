# SPK Ocular 1.1.2

- 使用 Go 1.26.9 和 golang.org/x/net v0.60.0 构建，修复新公布的 HTTP/2 漏洞。
- 浏览 Kubernetes 和 Docker 容器文件：缓存目录树、符号链接目标、语法高亮，以及最大 2 MiB 的 UTF-8 文件保护式编辑。桌面应用可通过原生目录选择器复制完整文件或文件夹，采用流式传输且不会覆盖已有名称。
- 在独立原生窗口查看日志，同时保持单一数据流。可选择纯文本导出的保存位置。显示所有日志级别，并保留文本过滤和搜索。
- 多 Pod 工作负载可选择 Pod，多容器 Pod 可选择容器。右键点击 Logs、Terminal 或 Files 打开完整设置；只有 Terminal 提供命令输入。只有一个选项时左键直接打开，但设置中的选择器仍然可见。
- 查看保留的 Deployment 修订版本，并将只读 Pod 模板 YAML 与当前 Deployment 或其他修订版本比较。
- 快捷键按物理按键识别，不受键盘布局影响，编辑器命令也适用。修复西里尔字符重复输入、拖动时的中间终端尺寸更新，以及分隔线残留焦点。
- 改善文件检查器空间、目录树宽度调整、缓存条目计数和稳定的加载/空目录行。错误提示不再移动布局。相关资源采用紧凑行，窗口操作改为右侧图标。

文件操作需要运行中的 Linux 容器和 sh；符号链接需要 readlink，下载需要 tar。原生下载不受编辑器 2 MiB 限制，并需要桌面应用。危险归档条目和目标名称冲突将被拒绝。

提供 Linux、Windows 和 macOS 的 amd64 与 arm64 原生安装包。不改变现有签名/公证状态，也不会改写旧版本发布文件。
