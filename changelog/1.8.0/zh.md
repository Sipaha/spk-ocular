# SPK Ocular 1.8.0

- 可在支持语法高亮、搜索和撤销的编辑器中修改单个 ConfigMap 值。确认界面显示与当前值之间的精确文本差异；二进制条目和 Secret 内容继续采用原有的受保护展示方式。
- 资源搜索支持显式输入 namespace、类型和名称片段。namespace 匹配不唯一时提供选择；唯一的实时结果会打开准确对象，同时保留对未保存修改的保护。
- 导航分组采用统一的图标和间距。折叠分组会隐藏包括当前资源在内的所有子项，同时保留已打开页面。
- 未连接工作区提供静态供应方预览、状态旁的 Connect/Cancel，以及相互独立的透明灯塔和山景插图。手绘灯塔及柔和光束保持固定尺寸，侧栏宽度变化时只裁切而不缩放。
- 统一的底部状态栏显示当前视图状态。刷新详情在两秒后出现，不会推移工具栏控件；嵌套面板的焦点和尺寸变化不会移动应用框架。
- 使用 Alt+Shift+方向键调整焦点所在面板的尺寸。Alt+Shift+Enter 可分离或收回日志，同时保持单一数据流；新窗口会使用当前屏幕更多的工作区域。
- 底部面板菜单可关闭全部标签页或左侧、右侧标签页，并保留固定标签页及其归属规则。
- 资源详情采用更清晰的字体层级，以及风格一致的紧凑修订记录和 Events 表格。Events 保留排序、列宽调整和 Refresh；Ingress 与服务的关联会显示每一条声明的路由路径。
- 修复 IME 替换操作可能重复发送终端中已提交文本的问题。活动输入组合、Unicode 粘贴和屏幕阅读器朗读缓冲区仍受保护。
