# Бэклог (после MVP)

- **Docker Compose provider** — следующий provider; проверка абстракции (см. спецификацию).
- Docker provider, SSH provider (`~/.ssh/config`), кастомные provider-ы.
- Интеграция с агентами Claude/Codex (поэтому состояние сразу в SQLite — решение пользователя
  2026-09-29).
- Несколько активных кластеров одновременно / несколько окон.
- CRD-виды (generic-колонки, `additionalPrinterColumns`).
- macOS и Windows сборки и упаковка (nfpm deb/rpm, AppImage).
- Редактирование/apply YAML.
- Раскрытие значения Secret по явному действию (сейчас YAML показывает `<N bytes>`).
- Память WebProcess при больших таблицах (95 МБ с 3k строк): не держать в JS полный массив
  строк, ленивый рендер ячеек, пагинация дельт.
- Отзыв RBAC при открытой таблице: существующий watch живёт до таймаута apiserver — показать
  «права могли измениться» по первому 403 при переподключении (проверить на kind).
- Переиспользование более широкого уже открытого кэша (all namespaces → один namespace) —
  отложено до замеров, где это даст выигрыш.
- Ширины/порядок колонок в `target_state`.
